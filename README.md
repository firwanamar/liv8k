# حسابات Trio Hub

أداة لمتابعة الدخل والمصاريف وصافي الربح وأرباح الشركاء شهريًا — مبنية بـ React + Vite.

## التشغيل محليًا على جهازك

تحتاج **Node.js** متثبّت على جهازك (نسخة 18 أو أحدث).

```bash
npm install
npm run dev
```

بعدها افتح الرابط اللي هيظهرلك (عادةً http://localhost:5173).

## الرفع على Vercel

### الطريقة الأسهل (عن طريق GitHub)
1. ارفع كل ملفات المشروع دي على مستودع (repository) جديد في GitHub.
2. روح على [vercel.com](https://vercel.com) واعمل **New Project** → **Import** للمستودع.
3. Vercel هيتعرّف تلقائيًا إنه مشروع **Vite** — سيب الإعدادات زي ما هي واضغط **Deploy**.
   - Build Command: `npm run build`
   - Output Directory: `dist`

### بدون GitHub (سحب وإفلات)
شغّل `npm run build` على جهازك، وبعدها اسحب مجلد `dist` على [vercel.com](https://vercel.com)، أو استخدم Vercel CLI:
```bash
npm i -g vercel
vercel
```

## ملاحظات مهمة
- **البيانات بتتحفظ في متصفحك** (localStorage)، يعني كل جهاز/متصفح ليه نسخته. مش بيتزامن بين الأجهزة.
- في الأداة زر **"استرجاع"** بيرجّع البيانات الأصلية، وزر **"تصدير"** بيطلّع ملف CSV.
- لو عايز البيانات تتزامن بين كل الأجهزة، محتاج قاعدة بيانات (زي Supabase أو Firebase) — أقدر أساعدك في ده لو حبيت.
